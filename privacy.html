Jon Fleet Mail - Privacy Policy

Last updated: 28 October 2026

What data the app accesses

Jon Fleet Mail uses the Gmail API with read-only access (the gmail.readonly scope). It reads Gmail message metadata (such as sender, subject, date and thread) and message content, only for Jon Kalkstein's own Google account. It has no other users.

How the data is used

The data is used only to notice replies to emails Jon is waiting on and to notify Jon that a reply has arrived. It is not used for advertising, profiling, or any other purpose.

Sharing

The data is not sold, rented, or shared with anyone.

Storage

Data is stored only on Jon's own computer. The app runs no servers of its own and keeps no copy of Gmail data anywhere else.

Google API Services User Data Policy

Jon Fleet Mail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
